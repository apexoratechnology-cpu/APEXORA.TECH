# APEXORA.TECH

Official website for **Apexora Technology**.

## Overview
This repository contains the source code for the APEXORA.TECH website, including company portfolio, services (Software Projects, Canva Designs, 3D/Design, and Zenvix associate), customer reviews, team highlights, and contact information.

## Getting Started
Open `index.html` in any modern web browser to view the site locally.

## Deployment
This static website can be deployed directly to:
- **GitHub Pages** (Settings > Pages > Deploy from a branch > `main` / root)
- **Vercel**
- **Netlify**
- Any static hosting provider
